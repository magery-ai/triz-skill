# Stage 6: Deliver the plan

> Draft for v0.1. Expanded in v0.3.

**Goal:** give the user something to act on now and a record of why.

## Steps

1. Fill `templates/plan-short.md` and show it in chat.
2. Fill `templates/plan-full.md` and write it to
   `triz-plans/YYYY-MM-DD-<slug>.md` in the user's project, where `<slug>` is
   the problem in 3-6 lowercase words joined by hyphens.
3. If you have no file access, return the full plan in the conversation.
4. Tell the user where the full plan was saved.

In autonomous mode, also fill the Assumptions section and the confidence level.
