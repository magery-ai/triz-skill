# Stage 4: Turn directions into concrete actions

> Draft for v0.1. Expanded in v0.3.

**Goal:** turn each direction into actions the user can actually take.

## Steps

1. For each direction write 1-3 actions. Each action names who does what, with
   what, and what it changes.
2. Every action must use at least one resource or respect a constraint from
   stage 1. Drop actions that only restate the principle.
3. Score each action:
   - **IFR fit:** how close it gets to the ideal result (high/medium/low).
   - **Effort:** cost and effort (low/medium/high).
   - **Side effects:** new problems it might create.
4. Rank the actions and recommend the top 2-3.

## Output

A ranked option list with the top 2-3 recommended.
